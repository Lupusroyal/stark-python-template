# Stark Python Template

Template profissional para projetos Python.

---

## Objetivo

Este projeto serve como base para novos projetos Python.

Inclui:

- Estrutura organizada
- UV
- Ruff
- Pytest
- Docker
- Docker Compose
- GitHub Actions (em breve)

---

## Estrutura

```text
src/
tests/
docs/
scripts/
```

---

## Instalação

```bash
uv sync
```

---

## Executar

```bash
make run
```

---

## Testes

```bash
make test
```

---

## Lint

```bash
make lint
```

---

## Formatação

```bash
make format
```
